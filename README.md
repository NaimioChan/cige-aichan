> 本仓库是 [@yukinsnow](https://github.com/yukinsnow/cige-chan) 的 [词格酱](https://github.com/yukinsnow/cige-chan) 的 fork，在原版基础上加入了 **AI 填词** 与 **主题色** 两个功能（详见下方「本 fork 的改动」）。

名字是「词格」+「酱」——后者取日语 ちゃん 的亲昵后缀。

## 这是做什么用的

写中文歌词的时候，作曲经常会先给一个"词格"——每句几个字、哪里停顿分组，
比如 `2/2/3` 就是"两个字、两个字、三个字"这样一句。词格酱就是把这种格子
摆出来，让你对着格子逐字填词，输入法直接连打，不用自己数字数、防止超格或者漏格。

## 原版功能

- 按词格摆格子逐字填词，点哪个格子就写在哪个格子
- **格子是钉死的**：打字覆盖当前格，不会把后面的字往后顶；删字原地留成空格，后面的字也不会往前挪。先写好的句尾始终待在自己的格子里，不会被推出词格丢掉
- 可以先落句尾几个字、前面留空慢慢填
- 句内停顿分组（如 `2/2/3`），加减格只作用于光标所在的分句
- 整句写偏了可以用 `Alt + ←/→` 左右挪一格，词格不动；会把字挤出词格时会拦住
- 每句可以存多个备选写法，随时切换对比，切换前自动保住没保存的版本
- 每句可以加备注，不占格子
- 自定义背景：图片 / 纯色 / 两套底色，蒙版与模糊都能调
- 支持导入 txt 词格、或者拿现成歌词反推出词格；导出歌词（分句之间会留出空格，所以导出的歌词能被原样再导入回来；可以选是否带上全部备选写法与备注）、导出词格、导出工程文件
- **（实验）日语拗音**：打日语歌词时，`きゃ` `しゅ` `ちょ` 这类拗音会自动跟前一个假名拼成一格，显示为主字右下角的小字，不单占格子，数格子时按音拍算而不是按字符数；促音 `っ／ッ` 不算在内，仍然独立占一格
- **韩语兼容**：谚文（如 `한`）本身就是一个完整的 Unicode 字符，天然一格一个音节，直接填字就行
- **（实验）MIDI 导入/导出**：按旋律的音符数量自动生成词格，用三个 keyswitch（C0 分句／C#0 换句／D0 换段）当分段标记。导入一份没放 keyswitch 的 MIDI 时会先提示——所有音符会挤进一句，导入后得自己动手分句分段——确认了才导。配套两种导出：去掉 keyswitch 的纯净 MIDI，以及带逐句校验的歌词版 MIDI（词格跟音符数量对不上会直接拦住，不会导出错位的歌词；歌词版能被 Synthesizer V 等支持 MIDI 歌词的软件读取）
- **界面语言**：中文 / 繁體中文 / 日本語 / 한국어，右上角下拉切换，帮助面板等长文本说明也会跟着换

## 本 fork 的改动

### AI 填词（实验功能）

顶栏新增「AI 填词」按钮，接入任意 **OpenAI 兼容接口**（各类中转站、one-api / new-api 自建站都行）：

- 面板里填接口地址 BASE_URL（结尾的 `/v1` 会自动补）、API Key、模型名，再写一段**风格提示词**——主题、押韵、意象、口吻，怎么写都行
- **整首填词**：AI 逐句把空格填上。每次请求都会带上全曲进度（各段各句的词格与已填内容）和你的风格提示词；AI 返回后**本地逐格核对字数**——分句数、每分句字数必须和词格完全一致，对不上就带着具体错误（"第 1 分句写了 5 字，词格是 4 格"）自动重试，最多 4 轮，仍不过就跳过该句并记入日志。**字数不对的词永远不会被写进格子**
- **检查全篇**：AI 通读全曲，从押韵、意象、叙事连贯的角度给出逐句替换建议；每条建议同样先过本地逐格校验，不合格的自动舍弃，只采用改对了的
- 字数统计规则与应用本体完全一致（日语拗音按音拍算一格）
- 接口地址、Key 和所有设置只存在本机浏览器的 localStorage 里，**不进工程文件、不跟着导出**
- 运行日志实时显示每句的填写思路 / 替换理由 / 跳过原因

> 注意：浏览器直连接口要求中转站允许跨域访问（CORS），常见的 one-api / new-api 系中转站一般都支持。

### 主题色

「背景」面板新增「主题色」区块，9 种强调色随选（默认 / 水蓝 / 松绿 / 紫藤 / 海棠 / 黛青 / 橘柚 / 墨灰 / 朱砂）：

- 只换界面强调色（按钮、光标、高亮、选中态……），底色的明暗结构不受影响
- 每种颜色在夜间、稿纸两套底色下各配了一档明度，保证对比度
- 选择跟随应用一起存在本机

## 怎么用

**电脑安装版（Windows / macOS / Linux）**：去 [Releases 页面](../../releases) 下载对应平台的安装包。
这些包没有做付费签名，首次打开时系统会拦一下，这是正常现象：

- **Windows**：点「更多信息」→「仍要运行」
- **macOS**：右键点应用 →「打开」→ 再点弹窗里的「打开」，只需做一次
- **Linux**：AppImage 记得 `chmod +x` 后运行，或者直接装 `.deb`

**Android 版**：同样去 [Releases 页面](../../releases) 下载 `.apk`，安装时系统会提示"未知来源"，
允许一下就行。

**iPhone / iPad**：暂时没有现成的安装包。如果你熟悉开发环境，也可以自己拉源码构建 iOS 版。

**从源码运行（网页版）**：`src/` 是自包含的纯静态页面，本地起一个静态服务器指向它即可，例如 `python -m http.server --directory src`。

## 关于数据

歌词内容只存在你自己的设备本地（浏览器或应用的本地存储里），不会传到云端、
也不会经过任何服务器。AI 填词功能只在点下按钮时把词格与已填内容直接发给你自己配置的接口地址，不经过任何中间服务器；接口配置同样只存本机。换设备、换浏览器，或者清了本地数据之前，记得先导出一份工程文件备份，不然找不回来。

## 开发

- `src/`：应用本体，自包含的 HTML / JS（`index.html` 编辑器 + `feature.html` 介绍页 + `i18n.js` 文案字典 + `ai.js` AI 填词模块）
- `src-tauri/`：Tauri 2 桌面/移动端壳
- `scripts/verify-ai.mjs`、`scripts/verify-accent.mjs`：无头 CDP 验证脚本（Node ≥ 22，配合本地静态服务器与 CDP 浏览器使用）
